# POSS POSS — UI 设计规范

## 色彩体系

### 主色
| 色值 | 用途 | 预览 |
|------|------|------|
| `#A8D8EA` | 主色（按钮、标签、强调） | 淡蓝 |
| `#B8E0F0` | 浅主色（背景渐变、卡片边框） | 浅淡蓝 |
| `#E3F2FD` | 最浅主色（页面背景、大底色块） | 极淡蓝 |
| `#64B4D2` | 深主色（文字按钮、图标） | 中蓝 |

### 中性色
| 色值 | 用途 |
|------|------|
| `#262626` | 正文文字 |
| `#737373` | 次要文字、图标 |
| `#FFFFFF` | 卡片背景、按钮文字 |
| `#F5FAFC` | 页面底色 |

### 功能色
| 色值 | 用途 |
|------|------|
| `#FF9500` | AI 模式标识 |
| `#34C759` | 成功提示 |
| `#FF3B30` | 错误/删除 |
| `#8E8E93` | 禁用状态 |

## 字体

| 场景 | 字号 | 字重 |
|------|------|------|
| 大标题（页面主标题） | 32px | Bold (w700) |
| 标题（卡片标题） | 20px | SemiBold (w600) |
| 副标题 | 16px | Medium (w500) |
| 正文 | 14px | Regular (w400) |
| 辅助文字/标签 | 12px | Regular (w400) |
| 微小文字 | 10px | Medium (w500) |

字体使用系统默认（SF Pro / Roboto），不引入额外字体文件。

## 间距

| 级别 | 值 | 用途 |
|------|-----|------|
| xs | 4px | 紧凑内容之间 |
| sm | 8px | 相关元素之间 |
| md | 16px | 卡片内部、列表项之间 |
| lg | 24px | 段落之间、页面内边距 |
| xl | 32px | 大区块分隔 |

## 圆角

| 级别 | 值 | 用途 |
|------|-----|------|
| s | 8px | 小标签、chips |
| m | 12px | 图片、小卡片 |
| l | 16px | 按钮、输入框 |
| xl | 20px | 大卡片、主页按钮 |
| full | 999px | 胶囊按钮、头像 |

## 阴影

| 级别 | 参数 | 用途 |
|------|------|------|
| 轻 | `blur:6, opacity:0.04, y:2` | 列表卡片 |
| 中 | `blur:12, opacity:0.06, y:4` | 主要按钮 |
| 重 | `blur:20, opacity:0.08, y:8` | 浮层、弹窗 |

## 组件规范

### 主按钮（Primary Button）
```
高度：56px
圆角：20px（xl）
背景：主色 #A8D8EA
文字：白色 Bold 16px
阴影：中
```

### 次按钮（Secondary Button）
```
高度：52px
圆角：20px（xl）
背景：白色 20%透明（放在有色背景上）
文字：白色 Medium 16px
边框：白色 50%透明 1px
```

### 胶囊标签（Chip）
```
内边距：水平16px 垂直8px
圆角：full
选中态：主色背景 + 白色文字
未选中态：极淡蓝背景 + 次要文字色
```

### 卡片（Card）
```
内边距：16px
圆角：16px
背景：白色
阴影：轻
```

## 图标

使用 Material Icons + Cupertino Icons（Flutter 内置）：
- 相机：`Icons.camera_alt`
- 历史：`Icons.history`
- 设置：`Icons.tune`
- 保存：`Icons.download`
- 删除：`Icons.delete_outline`
- 人数：`Icons.people`
- 倒计时：`Icons.timer`

## 动画

- 页面切换：Material 默认路由动画
- 按钮点击：缩放 0.95x → 1.0x（150ms）
- 倒计时数字：弹性缩放 + 淡入淡出
- 拍照闪烁：白屏 100ms
