# POSS POSS — 开发执行步骤

## 总体原则

1. **小步快跑**：每天只做 2-3 个连贯的功能点，不做大跃进
2. **先跑通再优化**：功能通了才加动画和美化
3. **每步可验证**：每天收工前 `flutter run -d chrome` 确认不报错
4. **问题记录**：遇到坑立即记到当天的 daily-log

---

## 阶段 0：环境搭建

### 0.1 Windows 安装 Flutter
- [ ] 下载 Flutter SDK（https://docs.flutter.dev/get-started/install/windows）
- [ ] 解压到 `C:\flutter`
- [ ] 添加 `C:\flutter\bin` 到系统 PATH
- [ ] 安装 VS Code + Flutter 插件
- [ ] 安装 Android Studio（仅需 SDK，不需要全部组件）
- [ ] 终端运行 `flutter doctor` 确认全绿

### 0.2 项目初始化
- [ ] `flutter create --org com.possposs poss_poss`
- [ ] 配置 `pubspec.yaml` 依赖
- [ ] 运行 `flutter pub get`
- [ ] 创建 `lib/` 下全目录结构
- [ ] 运行 `flutter run -d chrome` 看到默认页面

**完成标准**：Chrome 浏览器打开 App 看到 Flutter 默认计数器页面
