# POSS POSS — 产品需求文档

## 产品定位

一款帮助不懂拍照摆姿势的用户轻松拍出好看合影的 iOS/Android App。用户只需拍一张场景照，输入人数和年龄段，App 自动分析场景并在地面上叠加姿势指引，用户按指引站位即可拍出自然不单调的合照。

## 目标用户

- **主要用户**：18-45 岁普通手机用户，不太会摆姿势拍照
- **使用场景**：朋友聚会、家庭出游、情侣约会、团建活动、旅游打卡

## 核心功能

### P0（必须实现）

| 功能 | 描述 | 验收标准 |
|------|------|----------|
| 场景拍摄 | 调用相机拍一张场景照，或从相册选取 | 能正常拍照/选图，预览后可确认或重拍 |
| 参数输入 | 输入人数（1-20）+ 选择年龄段 | 滑动选择器正常工作，年龄标签可切换 |
| 模板姿势生成 | 根据人数和年龄段从本地模板库匹配站位 | 1-20 人都能返回合理的站位布局 |
| 姿势可视化 | 在照片上叠加半透明人形轮廓 + 姿势名称标签 | 轮廓清晰可辨，不遮挡主要场景 |
| 站位拖拽调整 | 用户可拖动每个站位标记到合适位置 | 拖拽流畅，位置跟随手指 |
| 拍照保存 | 倒计时后拍照，保存到系统相册 | 倒计时动画正常，照片能存到相册 |

### P1（重要）

| 功能 | 描述 |
|------|------|
| AI 智能分析 | 上传场景照到 DeepSeek API，生成个性化姿势 |
| 历史记录 | 查看之前拍摄的照片和参数 |
| 姿势详情 | 点击站位查看姿势详细描述和参考图 |

### P2（锦上添花）

| 功能 | 描述 |
|------|------|
| 分享功能 | 分享照片到社交平台 |
| iCloud 同步 | 多设备同步历史记录 |
| 内购系统 | AI 使用次数购买 |

### 不做什么

- 不做实时人脸识别（太复杂，V1 不需要）
- 不做视频录制
- 不做美颜滤镜
- 不做社交功能（评论、点赞等）

## 用户流程

```
启动 App → 主页
              ├→ "开始拍照" → 拍摄场景照 → 确认 → 设置参数（人数/年龄/风格）
              │                                             ↓
              │                              生成姿势指引（模板 或 AI）
              │                                             ↓
              │                              预览姿势叠层 → 拖拽调整站位
              │                                             ↓
              │                              倒计时拍照 → 查看结果 → 保存相册
              │
              └→ "查看历史" → 卡片列表 → 点击查看详情 → 可删除
```

## 非功能需求

- 离线可用（模板模式不需要网络）
- 打开 App → 拍完照不超过 2 分钟
- UI 响应流畅，不卡顿
- 所有文字用中文
